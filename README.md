# Diabetes_Prediction
Diabetes Prediction is a machine learning project that predicts whether a person is likely to have diabetes using health related data such as glucose BMI blood pressure age and insulin. Logistic Regression is used for prediction and performance is evaluated using accuracy classification report and confusion matrix.
DIABETES PREDICTION

PROJECT OVERVIEW

This project uses machine learning to predict diabetes based on health related information.

OBJECTIVES

Analyze diabetes data

Clean missing values

Prepare data for machine learning

Train a prediction model

Predict diabetes outcomes

Evaluate model performance

TOOLS USED

Python

Pandas

Matplotlib

Scikit learn

DATASET FEATURES

Pregnancies

Glucose

Blood pressure

Skin thickness

Insulin

BMI

Diabetes pedigree

Age

Outcome

TARGET

0 means No Diabetes

1 means Diabetes

METHOD

The dataset is cleaned and divided into training and testing data. The features are standardized using StandardScaler. Logistic Regression is then used to predict diabetes outcomes.

EVALUATION

The model uses accuracy classification report and confusion matrix to measure performance. A scatter plot is also created to analyze glucose and BMI.

HOW TO RUN

Install Python

Install the required libraries

Run the diabetes prediction Python program

CONCLUSION

The project demonstrates how machine learning can be used to predict diabetes from health related data. This project is intended for educational purposes and is not a medical diagnostic tool.
